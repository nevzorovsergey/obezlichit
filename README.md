# obezlichit

Обезличивание постановлений о штрафах за перегруз и «Платон» прямо в браузере: ФИО, номер
машины, УИН, ИНН, ОГРН и адреса подменяются вымышленными значениями той же формы. Файл не
покидает компьютер. Страница — `https://obezlichit.tonnaprava.ru`, решение —
ADR-0131 проекта «Тонна права».

## Как это устроено

Подмена идёт прямо в потоке команд PDF: коды глифов в операторах `TJ` заменяются кодами того же
шрифта, разница ширины компенсируется. Шрифт, кегль, положение строк и порядок текстового слоя
остаются как в оригинале, поэтому обезличенный файл разбирается так же, как настоящий.
QR-коды и штрихкоды перерисовываются с подменёнными данными, фото машины размываются,
метаданные удаляются, файл собирается заново без старых ревизий. Перед скачиванием страница
открывает результат и ищет в нём исходные значения.

Ядро — TypeScript без WASM: [pdf-lib](https://github.com/Hopding/pdf-lib),
[pdf.js](https://github.com/mozilla/pdf.js) и свой разборщик потока (`src/core/pdf`).

## Запуск

```bash
npm ci
npm test
npm run cli -- постановление.pdf акт.pdf -o out/
```

Файлы одного комплекта передаются вместе — у них общая таблица подмен. CLI печатает таблицу
«что → чем» (исходные значения замаскированы, `--show` — показать) и пишет только файлы,
прошедшие самопроверку.

## Правила репозитория

- Настоящие документы в репозиторий не попадают: в тестах только синтетические PDF.
- Каждое изменение ядра — с тестом.
